The core methodology is an LLM-driven objective discovery pipeline. An LLM (GPT-4) is iteratively prompted to propose new preference optimization loss functions in PyTorch code. The process starts with an initial context of established loss functions and their performance. For each proposed objective function, unit tests are run for validity. Valid functions are then used to finetune a Large Language Model (LLM) and evaluated on a predefined downstream validation task (MT-Bench). The resulting performance metric (fitness) is fed back to the LLM as in-context examples, allowing it to iteratively refine its proposals based on past successes and failures. This meta-optimization approach leverages the LLM's knowledge for flexible selection and mutation of objective functions without requiring a pre-designed search space.
